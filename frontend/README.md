# Village Outreach Design System

## Brand Identity

Village Outreach is a community-centered mutual-aid application.
Its visual identity emphasizes warmth, accessibility, trust,
and neighborhood connection.

## Style Tile

See [Village Outreach Style Tile](village_outreach_style_tile.png).

## Brand Colors

The canonical palette values are maintained in:
`../../frontend/assets/brand/color_palette.json`

## Typography

- Nunito: Headings and section titles
- Inter: Body text, forms, buttons, and navigation
- Raleway SemiBold: Brand wordmark and limited accents

## Logo Usage

- Use the approved logo without stretching or distorting it.
- Preserve the original aspect ratio.
- Maintain sufficient clear space around the logo.
- Use a background that provides good visual separation.
- Do not recolor or modify the logo without design approval.

## Flutter Implementation

Brand assets are stored in `frontend/assets/brand/`.
Theme colors and typography are defined in
`frontend/lib/core/theme/`.
